## 结论 {#conclusion}

满足「标准商品 + 已签收 + 未拆封」三个条件的订单，按签收次日 0 点起算，7 个自然日内可无理由退款。

## 退款窗口 {#refund-window}

- **起算点**：签收次日 0 点（不是下单时间，也不是发货时间）。
- **长度**：7 个**自然日**，含周末与法定节假日。
- **截止判定**：以退款申请提交时间为准，不以审核时间为准。
- **超期**：超期 3 个自然日内可申请一次人工特批，超过则不再受理。

## 例外与反例 {#exceptions}

- **不适用**：定制类商品、已激活的软件授权、已拆封的贴身用品。
- **常见误判**：客户说"我下单才 3 天"——窗口从**签收**起算，不是下单。
- **反例**：某订单签收第 8 天提交申请但客服当天未处理，仍算超期，因为以**提交时间**为准。

- **有争议的点**：跨境订单是否适用本窗口，政策原文未明确。
- **尚未确认**：人工特批是否有次数上限（客服手册与政策原文表述不一致）。
